# Production pipeline (voice → pictures → animation → sound → QA → render)

Everything runs in the Remotion project in `video/` (Remotion 4.0.539, React 19, TypeScript). The user's
`anthropic-skills:2d-video-animation-skill` (cut-out cartoon Shorts) describes the same animation craft in general
terms; this file is the Lab Logic-specific version of it.

## Project layout
```
video/
  src/Root.tsx                 compositions: Iceberg (1080x1920), TrashSun (1920x1080), thumbnail Stills
  src/iceberg/                 the Short "Why don't we just tow an iceberg?" + shared building blocks:
    art.tsx                    palette C, Face, Berg, Tug, Tap, CapeTown, Sea, Sky, Sunburst, Pill, BigText,
                               DimArrow, Thermo, Calendar, Monitor, PriceTag, Rope, Puffs, Drop, textWidth()
    anim.ts                    clamp, lerp, easings, prog, pop (overshoot), wobble, shake (sines), rnd
```

Setup in a fresh container: `cd video && npm install` (uses registry.npmjs.org). Python: `pip install
opencv-python-headless fonttools brotli`. Chromium: `/opt/pw-browsers/chromium_headless_shell-1243/
chrome-headless-shell-linux64/chrome-headless-shell` (pass as `--browser-executable`).

## 1. Voice (ElevenLabs connector)
1. `creative_create_flow` (one flow per episode so voice, sfx and transcription share it).
2. `creative_generate_speech` - `voice_id: 1gZSmkYVRMS8w1i4plmP`, `model_id: eleven_v4`, `generations_count: 1`,
   plain text. **≤ 5,000 characters per take** (a 5,133-char take failed after being charged): split long-form at a
   section break and join the takes.
3. Poll `creative_get_flow_run_status`, download `content_url` with curl (storage.googleapis.com works).
4. Word timings: `creative_transcribe_audio` with `connect_from: [<tts node id>]` on the same flow (costs 0),
   then download `words_download_url`.
5. `scripts/voice.py KEEP TEMPO` joins takes, caps pauses (silence < −42 dB for ≥ 0.18 s) and remaps word times
   into `words.json`. Shorts: KEEP 0.26, TEMPO 1.1. Long-form: KEEP 0.5, TEMPO 1.0. (Paths at the top of the
   script point at the episode's `public/<ep>/vo/` folder - edit them for a new episode.)
6. Voice starts at 0.1 s (Short) / 0.4 s (long-form): `VO_OFFSET` in timing.ts.

## 2. Pictures (see higgsfield.md)
Reuse poses first. New pose/object → Higgsfield → download → `scripts/prep.py name=raw/file.png ...` (pass **all**
poses each time; it rewrites `sprites.ts`) → check on a pink sheet. Sprites are trimmed and scaled to 1600 px tall.

## 3. Animation rules (what worked)
- **Timing:** define every beat by the word it lands on: `ph('phrase', after)` / `at(word, nth)`; scenes start
  ~0.04-0.1 s before their first word. Phrase lookup must match apostrophes exactly ("train's", "here's").
- **Cuts:** one scene per idea, a hard cut with a 4-5% punch-in (`punch()`), whoosh on each cut. Within a scene,
  continuous camera moves (tilt down through the waterline, zoom out to show scale).
- **Characters:** pose swaps on the narrowest frame of a squash (never cross-fade); breathing on holds; tremble
  when scared; contact shadow. Scientist ~44 px head radius in Shorts, ~50-58 in long-form.
- **Objects with faces:** `Face` (moods happy, surprised, worried, scared, smug, squeeze, dizzy, neutral), pop
  open with overshoot, blink, look at the action. Sun, Earth, iceberg, tugboat, tap, trash bag all have faces.
- **Labels:** `Pill` (ExtraBold, sized from real glyph widths), `BigText` (Black with ink stroke and shadow),
  `Stamp` (red rubber stamp), `DimArrow` (measurement), `Bar` (comparison). They pop in with `pop()` on their word.
  In long-form wrap pills to 1.18× size for phone readability.
- **Effects:** splash drops, sweat drops, puffs with one merged outline, impact stars, meltwater blobs that
  shrink away (never fade outlined shapes).
- **Shorts frame 0 = cover** (title text + scientist + object on Sky Blue sunburst + small wordmark).
- **Long-form end card:** Sky Blue sunburst, wordmark, tagline pill.
- Long-form has **no burned-in captions**; deliver an SRT instead (built from words.json, ≤ ~70 chars per cue,
  no overlapping cue times).

## 4. Sound
- Sound effects from ElevenLabs `creative_generate_in_flow` (`node_type: sfx`, `eleven_text_to_sound_v2`,
  `generations_count: 1`, ~17 credits each). Prompts like "Short cartoon pop... 0.3 seconds, no music".
  The model often returns 1-2 s regardless of the asked length; loop beds in `sfx.py`.
- Library so far: pop, whoosh, crack, splash, horn, stamp, bonk, pages, drip, ocean bed, melt (iceberg);
  rocket, boom, printer, train, fire, fail (sun). Reuse them.
- `scripts/sfx.py` trims to onset, normalises to −1 dBFS, builds loops. Levels under the voice: whoosh −26/−27,
  pops −21/−22, impacts −9 to −16, beds −24 to −31 dB. Big hits in pauses.

## 5. QA (always, before the final render)
1. Contact sheets: `COMP=<id> REBUNDLE=1 node scripts/stills.mjs out/qa/sheet.png t1 t2 ...` and look at them.
2. Layout check (long-form, works for any composition that has the LayoutProbe):
   `node scripts/layout-qa.mjs <CompId> 2 out/qa/layout.jsonl && python3 scripts/layout_report.py
   out/qa/layout.jsonl 1920 1080` → must print nothing. It reports labels cut by the frame, labels overlapping
   each other, labels on the scientist, labels on objects tagged `data-obj` (Sun, Earth, planets) and text wider
   than its pill. Tag labels with `data-label`, objects with `data-obj`.
3. Fix → re-run until clean → look at stills of the changed spots.

## 6. Render and deliver
- Short: `npx remotion render src/index.ts Iceberg out/x-raw.mp4 --scale=2 --image-format=png --crf=16
  --pixel-format=yuv420p --concurrency=4 --browser-executable=<chromium>` (~10 min for 70 s on 4 CPUs).
- Long-form: same without `--scale`, `--crf=17` (~20-25 min for 5.5 min).
- Run long renders with the Bash tool's `run_in_background: true` - not with `&` inside a normal command (that
  background job gets killed when the command returns).
- Loudness: two-pass ffmpeg `loudnorm=I=-14:TP=-1.5:LRA=11` (`-c:v copy`, AAC 320k, `+faststart`).
- Verify: resolution, 60 fps, frame count = duration × 60, audio length, LUFS ≈ −14, peak ≤ −1 dBFS, file
  timestamp is new, and a few frames pulled from the final file show the latest fixes.
- Send the file to the user with the file-sending tool; commit and push the project (renders stay git-ignored).
