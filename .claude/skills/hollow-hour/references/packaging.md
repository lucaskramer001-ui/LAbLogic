# Packaging

- **Title** < 50 chars + series tag: "The Town That Couldn't Stop Dancing [Record 001]" (see brand.md, competitor analysis v2).
  Not a question format (that is Lab Logic's).
- **Description:** line 1 = the event + place + year with search words; line 2 = the explanation hint; then
  "Sources you can check:" with links; then a line on what is disputed; then "Hollow Hour: real records, unreal
  stories." and 3-5 hashtags (#shorts #darkhistory #creepy #<topic>).
- **Tags** 10-15, < 500 chars: the event's names (dancing plague 1518, dancing mania, choreomania, Strasbourg 1518),
  people (Frau Troffea, John Waller), "dark history", "creepy history", "Hollow Hour".
- **Captions** for Reels/TikTok: the hook sentence + one question ("What would you have done?") is allowed as a
  caption, not in the video. 3-5 hashtags.
- Posting uses `publish/post.py` like Lab Logic but needs the Hollow Hour accounts and tokens first (not set up).
