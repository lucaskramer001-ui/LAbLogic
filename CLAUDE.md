# Lab Logic

This repo produces the Lab Logic cartoon-science channel (YouTube Shorts, Reels, TikTok, long-form YouTube).
For any work on videos, scripts, thumbnails, titles or posting, use the project skill
`.claude/skills/lab-logic/` - it holds the brand kit, the mascot references, the production pipeline in `video/`
and the lessons learned so far.

# Hollow Hour (sister channel)

The repo also produces Hollow Hour, a creepy / dark-history Shorts channel (true events, legends, experiments on
humans, hoaxes). For that work use the project skill `.claude/skills/hollow-hour/` - it reuses the same pipeline
with its own brand, papercut shadow-puppet kit (`video/src/hollow/`), narrator voice and fact-check rules.
